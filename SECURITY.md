# Security

Hasp holds no keys and cannot send NEAR. Do not add a seed, a private key, or a database URL to the repository or to an issue.

The rule is fixed: at most 0.02 NEAR, USDC only, once per account. A change that lets an agent move more than that, or move it more than once, is a defect.

Report a problem by opening an issue on this repository. Describe what you did and what the page said. Do not include a key, a seed phrase, or a connection string.
